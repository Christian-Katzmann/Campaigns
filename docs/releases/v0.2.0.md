# Campaigns 0.2.0

Plan in markdown. Run with Claude Code or Codex. Watch progress and review
evidence arrive on one local board.

This first public release brings the execution engine into the app, adds
structured final review and guarded rework, and keeps personal integrations and
Workflows hidden unless local capability detection enables them. It also ships
the companion planning and automation plugin, a rewritten quickstart,
cross-platform cleanup, HTTP integration coverage, and a macOS/Linux CI matrix.
