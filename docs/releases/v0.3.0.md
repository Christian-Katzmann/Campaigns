# Campaigns 0.3.0

Campaigns now carries a plan from local markdown through bounded execution,
review, CI evidence, and deterministic replay.

Highlights:

- Executable acceptance checks, plan linting, in-app planning, and launch estimates.
- Isolated worktrees, safe parallel lanes, live output, committed diffs, and rollback.
- Runner plugins, cross-family review, redaction, security documentation, and accessible controls.
- Kro and secure phone notifications, plus a cross-repository fleet view.
- A capped GitHub Action with redacted PR receipts and check runs.
- Campaign Markdown v1, the public run-state contract, a durable event journal,
  and a read-only static replay.

See [CHANGELOG.md](https://github.com/Christian-Katzmann/Campaigns/blob/main/CHANGELOG.md)
for the concise release history.
