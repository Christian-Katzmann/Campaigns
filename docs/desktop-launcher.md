# Desktop launcher

The optional desktop launcher is macOS-only. It wraps the local Node server in a native WebKit window so Campaigns can live in the Dock like a small desktop app.

## First launch

1. Build and install the app with `npm run desktop:build && npm run desktop:install`.
2. Right-click the app icon and choose **Open**, then click **Open** in the dialog. macOS remembers and skips this on subsequent launches (Gatekeeper, unsigned bundle).
3. Cold start is fast (~1 s) — the Node server has no compilation step.
4. If a "couldn't be opened" alert appears, open `~/Library/Logs/Campaigns/server.log`. The alert quotes the tail; the full log usually shows the cause.

## What it does

- Starts the Campaigns server (Node, no dependencies) on a free port (preferred `4178`, scans upward if busy).
- Opens a native macOS window pointing at the library page (`http://localhost:<port>/`).
- Reads/writes the registry at `~/Library/Application Support/Campaigns/registry.json`.
- Records the selected port at `~/Library/Logs/Campaigns/server.port` so paired skills can discover the running app.

## Launch behavior

The launcher is **persistent** — designed for daily use.

- **First click after boot:** ~1 s server boot + window paint.
- **Closing the window with the red X does NOT kill the server.** It stays warm. Click the icon again and the window opens within ~250 ms.
- **Cmd+Q (or right-click → Quit in the Dock) kills the server tree.**
- **Re-clicking the icon while the window is open** brings the existing window forward — no second window.
- **Sibling apps coexist** — if another launcher grabbed `4178`, Campaigns scans upward. Runtime port is recorded at `~/Library/Logs/Campaigns/server.port`.

## Manual stop

```bash
npm run desktop:quit       # or: ./scripts/desktop-quit.sh
```

Two-stage cleanup: TERM the recorded PID tree, then sweep stragglers from the runtime port.

## Logs

- `~/Library/Logs/Campaigns/server.log` — Node server stdout/stderr.
- `~/Library/Logs/Campaigns/server.port` — runtime port (most recent click).
- `~/Library/Logs/Campaigns/server.pid` — supervisor PID for cleanup.

## Rebuild after changes

```bash
npm run desktop:build && npm run desktop:install
```

Re-run when you change `server.mjs`, anything in `public/`, or the icon in `assets/`.

## Replace the icon

Drop a new 1024×1024 PNG or SVG at `assets/campaigns-icon.png` (or `.svg`), then:

```bash
npm run desktop:icons && npm run desktop:build && npm run desktop:install
```

The current icon is the placeholder generated by `scripts/placeholder-icon-gen.sh` (rings motif, paper-on-ink).
